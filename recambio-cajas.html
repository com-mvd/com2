Procedimiento de monitoreo

Para realizar estas tareas se debe utilizar en simultáneo el software para visualizar las cámaras de las plantas y el software de GPS «Punta tracking».

Registros a realizar

  • Registrar en Recambio de cajas cada vez que se llena una caja.
  • Registrar en Incidentes cualquier incidente que se visualice.
    • Descarga en una caja llena después de enviar el aviso.
    • El transportista deja el entorno sucio.
    • Verificar por GPS qué motocarro estuvo involucrado.

Reportes al grupo «Monitoreo plantas»

  • Enviar reporte cada hora del estado de las 3 plantas.
  • Informar cuando alguna de las cajas esté llegando a 3/4 de su capacidad.
  • Informar cuando alguna de las cajas llegue al 100% de su capacidad.
  • Informar al grupo «Monitoreo plantas» cuando se esté realizando un recambio de caja.

Reportes al grupo «Tareas Especiales + Municipio RECLAMOS»

  • Cuando una planta llegue al 100% de su capacidad, enviar mensaje de alerta con el siguiente formato:
    🚨(X PLANTA) LLENO, NO REALIZAR DESCARGA🚨
  • Cuando la planta que estaba llena reciba un vaciado, enviar mensaje de alerta con el siguiente formato:
    ✅(X PLANTA) SE PUEDE VACIAR✅
